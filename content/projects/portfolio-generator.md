## Overview

A tool that takes a developer's resume or GitHub profile and generates a ready-to-deploy portfolio site, aimed at developers who wanted a personal site without starting from a blank template.

## The challenge

Most developers wanted a portfolio site but didn't want to spend a weekend rebuilding the same hero/about/projects layout from scratch.

## The approach

- Built a generator that pulls project and profile data from a GitHub username or a short form.
- Used an LLM to turn raw resume bullet points into readable project descriptions.
- Output a static React/Tailwind site ready to deploy directly to GitHub Pages or Vercel.

## The result

Users went from a blank resume to a deployable personal site in minutes instead of a weekend, without touching CSS.

## Stack

React, Tailwind CSS, OpenAI, Vite.
